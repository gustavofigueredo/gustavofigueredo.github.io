# Portfólio — Gustavo Figueredo

Portfólio trilíngue de Gustavo Figueredo, Technical Writer com atuação em documentação de APIs, UX Writing, arquitetura da informação e sistemas de conteúdo.

## Páginas

- Portfólio em português, inglês e espanhol
- API Reference responsiva, baseada em OpenAPI
- Documentação funcional e playbook de lançamento
- Recursos nativos de acessibilidade

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- CSS Modules
- Vercel

## Executar localmente

Instale o Node.js e o pnpm. Depois, na pasta do projeto:

```bash
pnpm install
pnpm dev
```

Acesse `http://localhost:3000`.

## Validar a versão de produção

```bash
pnpm build
pnpm start
```

## Publicar gratuitamente na Vercel

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto para o repositório.
3. Acesse [vercel.com/new](https://vercel.com/new).
4. Importe o repositório.
5. Mantenha as configurações detectadas para Next.js e selecione **Deploy**.

Não há variáveis de ambiente obrigatórias.
